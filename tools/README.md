# hadistory — desktop tools

Scripts that run on a computer (not on the device), mainly to prepare content for the Pico version:

- Pre-rendering of story pages from `stories/` (image + text, font from `ressources/`) into the raw 600 x 448 7-colour format expected by the Inky Impression, ready to be copied onto the microSD card.

Generated output is not committed; it is rebuilt from `stories/`.
